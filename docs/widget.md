# Widget

Treadwheel provides a Web Component that adds an interactive widget to your
website, allowing visitors to unseal a given envelope.

## Importing the widget

To register the `<treadwheel-widget>` element, import the `treadwheel/widget`
module:

```javascript
import 'treadwheel/widget';
```

Alternatively, use a script tag to load it from a CDN:

```html-vue
<script type="module" src="https://cdn.jsdelivr.net/npm/treadwheel@{{pkg.version}}/dist/treadwheel-widget.min.js"></script>
```
